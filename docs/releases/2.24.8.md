# dsh-partner 2.24.8

## Mattermost 渠道启停与重连

- 在连接状态旁提供明确的“启用并连接”按钮；渠道运行中断或报错时，同一位置提供“重连”按钮，停用后不必滚动到面板底部寻找恢复入口。

- 沿用现有 `/channels/:id/enabled` 接口，没有变更 DSH Host 路由、请求方法或认证方式。

## 验证

- `npm run build` 通过；复用 `dsh-partner-dev` Profile 重启后，浏览器标题与面板均显示 `v2.24.8`，Mattermost 停用状态旁已显示“启用并连接”。真实 Mattermost 渠道仍保持停用，尚未验证实际启用及重新接收消息。
