# dsh-partner 2.24.7

## Mattermost 频道防回环

- 频道收件只构造其他用户明确 @机器人的帖子；普通频道消息和机器人自己的回复不进入 Durable Inbox、线程读取、确认或 Agent。
- Inbox 入口再次检查作者身份，防止传输层或上游数据误标后把机器人自己的回复当成新请求。
- 延续稳定帖子内容版本去重，线程回复导致根帖 `update_at` 变化时不会重复执行同一消息。
- Mattermost 官方 `GET /api/v4/channels/:channel_id/posts?since=` 按时间返回修改的帖子，没有仅按机器人提及过滤的参数；插件会在获得响应后立即过滤，仅提及进入 DSH 收件链路。
