# 2.23.18

QQ 设置新增「聊天互动」。消息表情回应及其查询、当前群基本信息、群成员信息和成员列表可作为公开聊天能力使用，不再依赖私有能力总开关。原操作开关保持不变，不自动启用原本关闭的项目；已获聊天许可的联系人和群成员可按场景使用已开启功能。

公开操作限定当前会话：群查询不能跨群；消息表情回应先核验真实消息所属群或联系人，再执行。发现换来源、撤销许可、关闭操作时停止。只公开当前会话能力，账号资料修改、空间、群管理、跨会话操作等仍按原私有权限处理。归属账号与可信任务已授权的高级能力沿用原范围。

消息表情回应是附在某条消息上的小表情，不是图片表情包；不要求为这种轻量互动先发一条任务播报。收藏表情原有前置回应规则不变。设置页将公开操作从私有列表移出，保留语音和表情收藏已有入口。

本次不修改群自动 @ 发言人设置，也未接入入群事件；不将公开成员查询等同于已能自动识别新人。兼容 DSH 0.2.1-rc.5。
