# dsh-partner 2.24.6

Fixes Mattermost channel mention intake and prevents replies from re-enqueueing the same thread root.

- Only posts that explicitly mention the configured bot enter the Mattermost channel Inbox, including replies inside an existing Thread.
- Non-mention posts are discarded before persistence and do not create batches, acknowledgements, or Agent turns; their timestamps still advance the channel cursor.
- Mattermost event identity follows the post content version rather than `update_at`, which can change when Thread activity is added to a root post.
- Keeps Mattermost REST paths and methods unchanged and retains DM routing and channel/thread authorization checks.

Verification: `npm run build` passed; the targeted Mattermost, inbox, routing, authorization, and delivery suite passed 104/104. Real Mattermost acceptance remains pending after restarting the existing `dsh-partner-dev` Profile and approving the channel contact.
