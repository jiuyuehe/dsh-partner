# dsh-partner 2.24.1

This iteration adds the Phase 1 Mattermost/WeChat routing and inbox data model:

- Typed inbound envelopes, stable conversation keys and source-bound outbound targets.
- Explicitly isolated memory scopes with opt-in channel/companion sharing.
- Branded identifiers for Session, Run, Subagent, Job, event, batch and delivery records.
- Draft SQLite Inbox, cursor, batch and outbound-delivery schema with reversible SQL migrations.

These definitions are not wired into channel processing yet. Phase 0's Plane exit gate remains unverified; this package is for review of the Phase 1 model and migration draft.
