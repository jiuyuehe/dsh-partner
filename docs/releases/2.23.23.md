# 2.23.23

将 2.23.22 的工具发现空答复特例替换为渠道请求的答复完成检查。模型正常停止且正文为空，不再直接视为成功：按当前用户输入的工具提交与交付记录，在原回合中最多恢复两次。没有实际工作提交时继续当前请求；已有工作提交时只能补交付或答复，工具入口拦截重复或新增工作，生成的文件只允许交付真实回执中的路径，附件重试只允许原 deliveryId。持续空白明确以错误结束，不触发回复后的概率自主活动。

附件工具新增成功渠道交付元数据；只认 channel=sent 和来源路由，文件生成、仅会话保存、发送失败不算渠道交付。已发图片而无额外文字不再报空回复，后续文字仍正常发送。元数据使用宿主已有工具结果结构，无新会话事件类型，不修改页面历史或滚动上下文。

普通文字、聊天终结工具、语音交付、明确静默保持原行为。检查只作用于当前渠道用户请求，尊重取消、agent 和来源隔离；自主活动提示明确不补跑旧的失败或未完成工作。不会按自然语言猜测任意任务是否达成，也不自动重放已提交的操作。

兼容 DSH 0.2.1-rc.5；不改变人物、关系、模型、记忆或权限设置。
