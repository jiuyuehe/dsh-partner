# dsh-partner 2.24.5

Adds the Phase 5 Mattermost channel and thread implementation for the `yly-mm-wx-up` iteration.

- Preserves verified two-person Mattermost DM routing and adds bot identity validation for channel mode.
- Adds explicit channel allowlists, exact bot mention checks, per-speaker approvals, and per-thread session/context isolation.
- Routes replies, progress posts, and file posts back to the verified source thread.
- Adds durable per-channel cursor scopes and preserves channel/thread context through inbox persistence and restart.
- Sends ordinary follow-up posts from the same authorized Mattermost DM or exact Thread into the running DSH Agent through native `steer`, leaving semantic goal grouping to the Agent.
- Keeps active insertion isolated by bot account, channel configuration, DM/channel, Thread root, actor authorization, and DSH reply ownership.
- Validates Mattermost attachment ownership against the originating channel before download.
- Recovers the Mattermost channel catalog for existing configurations that predate saved channel-directory data, without changing DSH request routes or methods.
- Displays the package version in the partner sidebar and panel title so the loaded build can be identified.

The Mattermost-targeted automated regression passes 103/103 tests. The Windows full suite is not green (1340/1369; 29 failures); observed failure categories are recorded in `docs/dev/phase-5-mattermost.md`, without assuming every failure is environmental. Real Mattermost browser acceptance remains pending.
