# 2.24.11

## Mattermost 收件上下文精简与 Agent 续接说明

- Mattermost Thread 历史读取改为使用官方 `perPage` 与 `direction=up` 参数，在服务端只取最近上下文和本批来源帖所需的有限数量；不会先下载整条 Thread 再在插件内截断。
- 发给 DSH 的用户正文明确保留来源元数据，区分同批较早的 USER 输入、本轮最新 USER 消息和引用 THREAD_HISTORY。最新用户消息是主要回应焦点；同批较早内容用于识别补充、指代和明确的独立目标。
- 在构造引用历史前过滤重复的机器人处理中回执和聊天状态提示；重复 BOT 历史回复只保留最新记录，用户重复输入仍按原文保留。
- Mattermost 的解释规则加入隐藏的 DSH system prompt；用户消息仍以 DSH 原生 USER 消息方式提交，工具列表继续由 DSH 实际工具 schema 提供。伙伴角色与“长期行为准则”仍由 `partner-identity` 生成并保留。
- 活跃 Agent 接收新消息时使用 DSH 原生 `steer`，其语义是当前模型/工具步骤结束后的下一步输入，不会中断正在执行的工具调用；渠道诊断文案已明确显示这一状态。
