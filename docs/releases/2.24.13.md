# 2.24.13

- Mattermost Thread 历史轮数可在渠道设置中调整，默认 3 轮，支持 0–10 轮。
- 同一来源、同一发言人的 Mattermost 消息在 30 秒内合批；每条获准消息仍立即确认。
- 单独的机器人提及只负责唤醒；插件从同一发言人最近的有效 USER 消息回退选择任务，不把 `@机器人` 当作任务焦点。
- DSH 用户消息把本轮实质任务放在开头，历史 USER/BOT 配对轮次放在后面；已知回执、重复 BOT 历史与渠道状态提示会过滤。
- 用户明确要求记住的纠正保存在对应 Mattermost 会话约束中；最近三个实质任务作为同一会话的话题链，并通过隐藏 system context 注入。
- 焦点回退会生成本地诊断警告，可在 DSH 页面 DevTools Console 中查看。
- 不新增 HTTP 路由；沿用现有 DSH 插件 API、频道白名单、授权、来源验证和 Mattermost REST 传输。
