# 2.23.33

修复动作登记中的两个边界：未知工具名导致已交付图片仍被误拦；同轮先回忆、再追加生图时新增动作被前置回应去重吞掉。

- expectedTools 在发送或登记前逐个核对当前工具注册；未知名字要求查询真实目录，不自动猜测别名，不授予权限。
- 同轮新增工具动作继续登记，不重复发送前置回应。普通接话仍可独立发送。
- 结束检查合并当前输入的全部已确认动作声明；查询目录、完成先前回忆不会抵销后登记的生图任务。
- 重复声明已登记动作不重新创建任务，不导致已生成图片自动重画；新输入和取消边界保持原逻辑。
- 修正通用工具说明中的旧前置回应示例，补齐 expectedTools。

不修改人物设定、语气词、历史展示或图片生成插件。最低 DSH 0.2.1-rc.2，部署目标 0.2.1-rc.5。
