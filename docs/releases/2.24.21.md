# 2.24.21

- Mattermost user messages now place the latest substantive USER request at the end of the DSH message; configured Thread history is included only for short, referential, or context-dependent requests.
- Active Agent follow-ups are explicitly framed as updates to the running task and do not inject a second copy of Thread history.
- The verified bot mention is removed from the user-facing task text, and unrelated historical TASK_CHAIN entries no longer accompany self-contained requests.
- Ordinary `partner_chat_reply` text remains available when role chat is disabled; regression coverage confirms the role toggle does not block channel text delivery.
- Real Mattermost testing confirmed receipt, same-Thread routing, and active steering, but the response quality gate failed because the channel session workspace could not read repository documents and stale history still distracted the model. Phase 5 remains open for manual DM verification.
