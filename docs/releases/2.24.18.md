# 2.24.18

- Active Mattermost messages from the same authorized DM participant or exact Thread now bypass the 30-second idle coalescing window and use native DSH `Agent.steer`.
- If DSH explicitly refuses a matched active Mattermost steer, the batch is quarantined with a visible diagnostic instead of becoming a later FIFO turn. Other senders and Threads remain separate sources.
- `Agent.steer` still takes effect at the next DSH step boundary; it does not interrupt an active model or tool step.
