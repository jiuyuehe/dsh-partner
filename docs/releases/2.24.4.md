# dsh-partner 2.24.4

Completes the P2 Durable Inbox, P3 dispatcher, and P4 WeChat contact-isolation implementation for the `yly-mm-wx-up-p2` branch.

- Persists WeChat messages and poll buffers atomically, deduplicates replay, and restores pending messages after restart.
- Delivers approved messages into per-contact DSH sessions with debounce, FIFO queues, parallel conversation lanes, and live authorization checks.
- Keeps WeChat context tokens scoped to the originating bot account and contact, and preserves inbound/outbound image and file delivery.
- Recognizes Windows absolute attachment paths and reports empty Agent replies as failed inbox work instead of silently completing them.
- Adds local F12 stage diagnostics and a manual acceptance guide for the existing `dsh-partner-dev` Profile.

Automated P2/P3/P4 targeted suites and the package check pass. Real WeChat account/browser acceptance remains a user-run gate.
