# 2.23.26

闲时自由活动同样可以承接先前用户消息和伙伴自己的回复，或回忆较早的话题；续话、独立活动、安静休息都是可选项。不再默认优先浏览空间或整理收藏，不要求外部新资讯或梦境才能聊天。回复后概率机会与闲时机会仍沿用原调度，但不是不同能力范围。

活动摘录保留最近八条对话，并补入最近三条用户消息及紧随其后的助手文本回应，去重后最多十四条，每条最多八百字符，带原事件时间。避免连续自主消息挤掉真实用户话题。只影响请求摘录，不修改会话存储、展示、滚动设置或记忆。

不再因来源为自主活动就每轮额外注入完整梦境；当前查询涉及梦时仍提供，已有会话中的梦和记忆不删除。旧静默活动理由不是后续禁聊结论。不自动恢复失败任务，不强制消息或工具调用，不改概率、权限与人物设定。
