# 2.23.28

支持当前私聊一轮内多次接话：开启角色卡与分段回复时，`partner_chat_say` 立即发送一句由角色写出的对白，收到送达回执后继续本轮。模型可再补一句、执行工具，最后使用 `partner_chat_reply` 结束；当前输入后已经接话送达且没有新内容时允许 `messages:[]` 安静结束。正常续话不再必须依靠回复后自主活动。

- 每轮最多六次中途接话，不要求用满，不靠固定等待或新后台任务延长对话。
- 实际送达回执进入既有工具事件；页面显示原话，最终交付不重发，中途接话不冒充最终任务答复。
- 排队发送串行化；输入变化阻止旧的排队接话，发送失败或结果不明不自动重试。渠道权限与取消检查保留。
- 任务前置回应仍独立执行，每次输入一次；中途聊天不自动放行任务。内部委派和闲时活动不使用此私聊入口。
- 保留 2.23.27 的自主表情整理去重复改进。

最低 DSH 0.2.1-rc.2；部署验证目标 0.2.1-rc.5。没有新增会话事件类型，不改历史存储或滚动上下文范围。
