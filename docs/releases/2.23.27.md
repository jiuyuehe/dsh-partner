# 2.23.27

自主浏览与表情收藏、备注、排序默认安静完成，工具操作结束不自动成为“发一张图再感慨一句”的理由。闲时与回复后延续共享这项引导：根据独立的交流意图选择聊天，结合近期表达识别换图、换措辞的重复分享。用户明确要求反馈、真实接梗或新语境下仍可使用合适的旧表情。

活动对话摘录保留纯图片/表情回复，并增加最多六条近期媒体回复摘要。仅包含有限配文、表情来源与标识、标签及时间，不重新加载图片、预览地址或附件路径。摘要标明提交记录不等于送达证明，不用于宣称交付成功；失败工具结果不采纳。原消息与会话历史不变。

不增加关键词拦截、固定发送冷却或永久禁用表情，不改变人物、概率、权限、用户请求投递或失败恢复。该版本改善自主决策依据，实际重复率需继续观察。
