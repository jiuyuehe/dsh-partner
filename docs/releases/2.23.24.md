# 2.23.24

角色聊天使用当前伙伴人格作为前部身份说明，并在模型请求装配时移除原封不动的 DSH 默认编码身份。用户修改过的预设、非伙伴工作会话、工具权限和审批继续保留。

统一工具入口启用时，已核对的宿主文件、终端、任务、后台作业和委派工具说明随 `partner_tools describe/load` 返回，不再全部常驻聊天系统上下文。直接暴露的工具继续保留说明；未知提示段不裁剪。关闭入口后恢复原说明。

角色聊天不再同时注入网页专用的 Markdown 本地图片交付说明，统一使用伙伴原有的附件、文字、语音和分段投递协议。此修改不改变工具结果、投递回执、页面历史或有效上下文滚动方式，不新增会话事件类型。

实现参考：dsh-whale-musume-persona 的预设身份定位、dsh-agent-persona 的作用域处理、Lume 的有界对白示例及 dsh-natural-dialogue 的聊天/工作分离。本版独立实现请求投影，未安装这些插件，也不增加每条回复的改写模型调用。人物对白示例属于用户角色配置，不将某个人物年龄、称呼或口癖写死在插件中。

验证包括首轮恢复、递归装配、权限变化、关闭恢复、工具说明按需返回、不同 agent 隔离，以及原有媒体投递、任务前回应和上下文滚动回归。语气属于模型行为，须结合真实对话体验验收。
